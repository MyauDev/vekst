# Status — 2026-09-19

Twelve days to the Demo. Nine of them are working days (Mon 21 Sep to Thu 1 Oct).

## 1. The short version

The code is almost complete. The Demo is not possible today.

Three items stop it. None of the three is code that a developer can write now:

1. **No production path creates an organisation.** `db.CreateOrganization` exists and
   works, but only tests call it. Sign-in creates a `users` row and a
   `user_identities` row and nothing else. A pilot customer who signs in holds zero
   memberships, so every RPC answers `ErrNotAMember`. No OpenSpec change owns this.
2. **D-6 is still open.** The host has no name. `deploy/k8s/overlays/` holds `local`
   only. There is no cluster, no DNS, no TLS and no backup. The provisioning change
   has no owner, no proposal and no budget.
3. **The founder has not supplied the pilot files.** Only the Priorbank (Belarus)
   parser exists. `core/testdata/` holds `priorbank-by` only. If a pilot customer
   banks with PKO BP or a Kazakh bank, the file does not parse.

Velocity is no longer the risk. The team delivered ten changes between 13 and 19
September. The risk is now three external dependencies.
